Entropy is a state function, so we can calculate values for a process using any path. This allows us to calculate the entropy change of a chemical reaction using standard entropies. Specifically, we sum the entropies of the products and subtract the entropies of the reactants:

[Note: corrected; the source prints "the entropies of the reactions:" where this reads "the entropies of the reactants:". Reactants.]

Δ_rxn S° = Σ_Products vi S°i − Σ_Reactants vi S°i

Where vi is the stoichiometric coefficient. Let's look at the combustion of methane:

CH4(g) + 2O2(g) → 2H2O(g) + CO2(g)

[Note: corrected; the source prints "→ 2H2O + CO2(g)" where this reads "→ 2H2O(g) + CO2(g)". The value 188.84 below is S° of gaseous water.]

The standard entropies are:

| Molecule | Entropy ((J)/(mol·K)) |
| --- | --- |
| CH4 | 186.25^1 |
| O2 | 205.15^1 |
| H2O | 188.84^1 |
| CO2 | 213.79^1 |

The entropy for the combustion of methane is:

ΔS° = [2(188.84) + 1(213.79)]−[1(186.25) + 2(205.15)] = −5.08 (J)/(mol·K)

[Note: corrected; the source prints "1(213.70)]" where this reads "1(213.79)]"; the source prints "= −5.17 (J)/(mol·K)" where this reads "= −5.08 (J)/(mol·K)". The table gives 213.79 for CO2; 591.47 − 596.55 = −5.08.]

A large number of reactions proceed through a series of steps that can collectively be classified as a chain reaction. The reactions contain steps that can be classified as

- initiation step – a step that creates the intermediates from stable species
- propagation step – a step that consumes an intermediate, but creates a new one
- termination step – a step that consumes intermediates without creating new ones

These types of reactions are very common when the intermediates involved are radicals. An example, is the reaction

H2 + Br2 → 2HBr

The observed rate law for this reaction is

rate = (k[H2][Br2]^(3/2))/([Br2] + k'[HBr])

A proposed mechanism is

Br2 ⇌ (k1, k_−1) 2Br^·

Br^· + H2 ⇌ (k2, k_−2) HBr + H^·

[Note: corrected; the source prints "2Br^· + H2 ⇌" where this reads "Br^· + H2 ⇌". One bromine atom, as the rate equations below have it.]

H^· + Br2 → (k3) HBr + Br^·

Based on this mechanism, the rate of change of concentrations for the intermediates (H^· and Br^·) can be written, and the steady state approximation applied.

(d[H^·])/dt = k2[Br^·][H2]−k_−2[HBr][H^·]−k3[H^·][Br2] = 0

(d[Br^·])/dt = 2 k1[Br2]−2 k_−1[Br^·]^2 − k2[Br^·][H2] + k_−2[HBr][H^·] + k3[H^·][Br2] = 0

Adding these two expressions cancels the terms involving k2, k_−2, and k3. The result is

2 k1[Br2]−2 k_−1[Br^·]^2 = 0

Solving for Br^·

Br^· = √((k1[Br2])/(k_−1))

This can be substituted into an expression for the H^· that is generated by solving the steady state expression for d[H^·]/dt.

[H^·] = (k2[Br^·][H2])/(k_−2[HBr] + k3[Br2])

so

[H^·] = (k2√((k1[Br2])/(k_−1))[H2])/(k_−2[HBr] + k3[Br2])

Now, armed with expressions for H^· and Br^·, we can substitute them into an expression for the rate of production of the product HBr:

(d[HBr])/dt = k2[Br^·][H2] + k3[H^·][Br2]−k_−2[H^·][HBr]

After substitution and simplification, the result is

(d[HBr])/dt = (2 k2((k1)/(k_−1))^(1/2)[H2][Br2]^(1/2))/(1 + (k_−2)/(k3) · ([HBr])/([Br2]))

[Note: corrected; the source prints "(1 + (k_−1)/(k3) ·" where this reads "(1 + (k_−2)/(k3) ·". The reverse of step 2, HBr + H· → Br· + H2, competes with step 3: k_−2, as k' = k_−2/k3 below.]

Multiplying the top and bottom expressions on the right by [Br2] produces

(d[HBr])/dt = (2 k2((k1)/(k_−1))^(1/2)[H2][Br2]^(3/2))/([Br2] + ((k_−2)/(k3))[HBr])

[Note: corrected; the source prints "([Br2] + ((k_−1)/(k3))[HBr])" where this reads "([Br2] + ((k_−2)/(k3))[HBr])". As above: k_−2.]

which matches the form of the rate law found experimentally (Equation (exp))! In this case,

k = 2 k2√((k1)/(k_−1))

and

k' = (k_−2)/(k3)
